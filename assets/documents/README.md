# Dokumente

Hier werden die PDF-Dokumente des Vereins abgelegt (Vereinsstatuten,
Datenschutz für Mitglieder,
Beitrittserklärung, Beitragsordnung, Spesenreglement, Haus- und
Platzordnung). Sobald eine Datei hier liegt, kann die entsprechende Karte in
`pages/vereinsdokumente.html` von einem "In Vorbereitung"-Platzhalter auf einen echten
Link (`target="_blank"`, `href="../assets/documents/<name>.pdf"`) umgestellt
werden.
